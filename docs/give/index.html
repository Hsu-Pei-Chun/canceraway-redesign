信用卡線上捐款（推薦）

採用 SSL 256 bit 加密金流。填寫線上捐款資料後選擇刷卡，輸入卡號即可完成，可選單筆或定期定額。

行動支付

方式怎麼做
LINE Pay在線上捐款頁選擇 LINE Pay，用手機 LINE 掃描 QR Code 完成。
全支付在線上捐款頁選擇全支付；電腦版掃 QR Code，手機版會自動跳轉。
街口支付App 首頁「公益捐款」→「特殊醫病」→ 財團法人台灣癌症基金會 → 我要捐款。
Pi 拍錢包iOS 掃描台癌專屬 QR 碼；Android 由「公益捐款」選擇台灣癌症基金會。
台灣Pay掃描台癌專屬 QR 碼，輸入金額與姓名電話。若未顯示姓名欄位，請完成後 Email 告知以開立收據。

超商捐款

  • 7-ELEVEN：ibon「儲值/繳費」→「慈善捐款」→「健康關懷類」→ 台灣癌症基金會；或 OPENPOINT App「服務」→「愛心公益」。
  • 萊爾富 Life-ET：繳費・代收 → 愛心捐款 → 台灣癌症基金會。
  • OK・go：繳費 → 愛心捐贈 → 其他社福 → 台灣癌症基金會。

請保留「代收繳款證明單」，方便日後查詢捐款紀錄。

定期定額

每月固定扣款，要停止只需一通電話。可用信用卡傳真授權（傳真 02-8787-5222）、郵局轉帳授權書或銀行 ACH 授權書，填妥後掛號寄回。

劃撥帳號1909-6916
戶名財團法人台灣癌症基金會
ATM持任何金融卡至台新、中國信託提款機選擇「捐款服務」；該兩行晶片卡免手續費。

手機語音捐款

  • 台灣大哥大：直撥 5180 再按 62
  • 中華電信：直撥 51162

語音捐款專線不收通話費，可線上索取收據。

發票愛心碼 1799

在開立電子發票的店家結帳時說出愛心碼 1799，就能把發票捐給基金會。

遺產與保單捐贈

可透過遺囑指定將部分或全部遺產捐贈給基金會，或在壽險保單中將「財團法人台灣癌症基金會」列為受益人之一。歡迎來電討論。

關於捐款人姓名公開

依《財團法人法》第 25 條，基金會須公開前一年度捐贈者的姓名與金額。若不同意公開，請在線上捐款頁勾選「不同意捐款姓名公開揭露」，或致電 02-8787-9907 由專人協助。
