多年來，感謝各界的協助與支持，投入全民無癌希望工程，台灣癌症基金會自1997年成立以來，不斷致力於癌症預防以及癌友關懷，我們期許帶領國人可以真正遠離癌症的威脅。在台灣，癌症是國人死亡原因的首位，而今，大約有40萬名癌症病友需要被關懷、被照顧，為此，我們更於南北兩處，各成立「癌友關懷教育中心」，提供癌友及家屬適切的照顧與服務。～癌症，需要長期抗戰，更需要周邊力量的支持～愛的起點由您開始，邀請您以實際行動，幫助癌友邁向康復之路。

依所得稅法第十七條第一項第二款規定，捐贈總額，個人不超過所得20％，營利事業不超過營業所得10％，可列為扣除額。誠摯歡迎企業朋友參與，為推廣癌症預防及促進癌症研究之整體發展而努力，一同為國人的健康把關。

推廣支持：

  1. 發票箱放置
  2. 支持1799愛心碼，若您是電子發票特約商店，歡迎鼓勵消費者於結帳時將發票捐贈給1799愛心碼，讓台灣癌症基金會成為您的特約愛心捐贈對象。
  3. 台灣癌症基金會季刊、文宣品放置。
  4. 提供公益廣告版面刊登（如：網頁banner連結等廣告）
  5. 贊助公益廣告露出（如：捷運燈箱、媒體等廣告）
  6. 訂閱並分享台灣癌症基金會電子報，掌握癌症與抗癌的健康新資訊，除幫助企業員工活出健康，透過分享基金會各項活動與資訊，也能將訊息傳遞出去。

贊助支持：

  1. 企業可以捐出收入的部分比例
  2. 企業鼓勵員工薪資轉帳定期定額捐款
  3. 邀請講座或提供活動贈品
  4. 提供毛帽或假髮、或癌症需要營養品贈送癌症病友
  5. 提供工作機會

義賣合作：

  1. 認購義賣商品作為企業活動贈品
  2. 公司福委會協助義賣商品
  3. 提供企業商品義賣，提撥所得捐贈
