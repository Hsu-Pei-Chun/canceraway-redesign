膽管癌（Cholangiocarcinoma），又稱膽道癌，是一種源自膽管上皮細胞的原發性惡性腫瘤，雖然發生率相對較低，卻以高度惡性著稱。根據衛生福利部國民健康署112年發布的癌症登記年報，膽管癌的新診斷個案呈現逐年上升的趨勢，多發生於60至70歲之間。此病雖不普遍，卻逐漸受到臨床重視。

膽管系統在人體中扮演著關鍵的角色，主要負責輸送由肝臟製造的膽汁，經由一系列微細管道，包括微膽管、小膽管、肝內膽管、總肝管，最後與膽囊及總膽管相接，將膽汁導入十二指腸，協助脂肪的消化吸收。整個膽道系統分布廣泛，涵蓋肝臟內外，因此膽管癌可發生於任何膽管組織的部位，依腫瘤發生位置可區分為肝內膽管癌、肝門膽管癌與遠端膽管癌三種類型，其中又以肝內膽管癌的發生率較高。由於膽管的結構如同一張網絡，當腫瘤發生時，往往會造成膽管狹窄與阻塞，進而引發阻塞性黃疸、膽管感染，影響肝功能。特別是肝內膽管癌，因其腫瘤位於肝臟深處，早期通常缺乏明顯症狀，待腫瘤變大才出現臨床表現，導致診斷時多為晚期，預後不佳。相對而言，肝外膽管與肝門區的腫瘤因靠近總膽管，體積即使不大，也容易造成膽汁排出受阻，使患者較早出現黃疸症狀，較易於早期偵測。

在面對膽管癌這類診斷困難、治療複雜且預後差的疾病時，深入瞭解其臨床表現，有助於早期診斷早期治療，延長生命期。

背景與成因

一、危險因子：目前膽管癌並未找出確切的致病原因，可能的危險因子如下：

  1. 持續性膽管慢性發炎，例如：原發性硬化性膽管炎（Primary sclerosing cholangitis，PSC）、肝臟寄生蟲感染，如中華肝吸蟲，發炎性腸炎患者以及纖維多囊腫肝，有較高機率發生膽管癌。
  2. 慢性膽汁鬱積：例如，膽管結石或先天膽道異常，據統計，肝內膽管癌有將近10%罹患肝內結石。另外因膽汁鬱積長期刺激，可能增加內皮細胞癌變的機率。
  3. 肝硬化：酒精性或病毒性（C型或B型肝炎病毒）導致的肝硬化。
  4. 接觸有毒物質：如，戴奧辛、二氧化釷（thorium dioxide）、多氯聯苯等有害物質。
  5. 肥胖、糖尿病。
  6. 膽管良性瘤：如膽管乳突狀瘤病。

二、預防與篩檢

膽管癌由於其發生率低、早期症狀不明顯且缺乏有效的篩檢工具，因此在預防與早期診斷方面，常面臨極大挑戰。透過降低相關危險因子、控制膽道慢性疾病及針對高風險族群進行監測，仍是目前可行的預防與篩檢策略。

在預防方面，最重要的是，減少慢性膽道發炎的發生、避免暴露於危險因子、定期檢查與治療膽結石與膽囊疾病、避免生食淡水魚（預防肝吸蟲感染）、積極治療病毒性肝炎與控制肝硬化，皆有助於降低罹癌風險。

篩檢方面，膽管癌目前尚無常規篩檢工具，主要因其缺乏特異性高的腫瘤標記與早期症狀，多半是在病程進展至引起阻塞性黃疸或其他症狀時才被診斷。然而，對於高風險族群，例如罹患原發性硬化性膽管炎、曾接受肝膽手術或有家族病史者，可考慮定期進行腹部超音波、磁振造影（MRI/MRCP）或電腦斷層掃描（CT）來追蹤病灶變化。此外，腫瘤標記如CA 19-9與 CEA 雖無法作為單一診斷依據，但在某些情況下可協助評估病情變化與治療反應。

分類

膽管癌的分類依解剖位置分為肝內、肝門周圍和遠端膽管癌。

一、肝內膽管癌：位於左右肝管分支的近端，多半腫瘤造成壓迫才有症狀，預後差。

二、肝門膽管癌：佔60-70%，位於左右肝管分支之間和膽囊管近端。

三、肝外膽管癌：總膽管與十二指腸範圍之內。

四、膽囊癌：有可能是膽結石或反覆膽囊炎，造成膽囊內黏膜癌變。女性發生率高於男性。

臨床症狀

一、黃疸（皮膚或眼白）：出現時間與腫瘤位置有關，若於肝外膽管或肝門膽管處，腫瘤壓迫阻塞膽汁排出就會較早出現。

二、深色尿液

三、灰白色糞便

四、腹部疼痛

五、發燒

八、不明原因的體重減輕

九、食慾不振

相關檢查

一、理學檢查：過去疾病史、家族史。

二、血液檢查：血球計數、生化指數及肝功能測試等，鹼性磷酸酶（alkaline phosphatase, Alk-P）、丙麩氨轉肽酶γ-GT （γ-glutamyl transpeptidase）、膽紅素（bilirubin）可能會升高，可做為診斷參考。

三、腫瘤指數：癌胚抗原（CEA）和CA 19-9，但腫瘤指數不具專一性，很多疾病也會造成數據升高，可用來追蹤及復發的參考依據。

四、超音波檢查：為初步診斷工具，評估腫瘤及位置，膽管有無擴張等。

五、電腦斷層：評估腫瘤的大小，膽管阻塞程度、周圍組織、器官及血管、淋巴侵犯的情況、以及有無遠端轉移。

六、核磁共振：判斷腫瘤位置，侵犯範圍。特別是搭配 MRCP（磁振胰膽管攝影）技術，可以清楚了解膽管結構與狹窄部位。

七、正子掃描：評估是否遠端轉移，期別診斷之參考。

八、磁共振胰膽管造影（MRCP）：身體內部區域（例如肝臟、膽管、膽囊、胰腺和胰管）進行一系列詳細的檢查。

九、內視鏡逆行性膽胰管造影術（ERCP）：需要麻醉執行。以內視鏡方式，將顯影劑注入膽胰管，檢查內部構造與病變。若有阻塞，可先以引流管、或支架擴張先緩解症狀。

十、經皮穿肝膽管攝影術（PTC）：注射顯影劑，顯像膽管各分支與阻塞處。如果有膽汁阻塞，可放置引流管（PTCD）引流膽汁。

癌症分期

依據AJCC第8版（2017）TNM分期：原始腫瘤大小（T），局部淋巴腺轉移的有無（N）以及遠處轉移的與否（M），分為四期。

治療方式

一、手術

手術切除病灶是重要的治療方法。手術後，依照病理組織及淋巴侵犯狀況，可能會再以輔助性化學療法或放射療法以殺死任何殘留的癌細胞，為要降低癌症復發的風險。

依手術部位可分為五種方式：

1. 切除膽管：如果腫瘤很小且僅在膽管中，可進行此手術，同時須做淋巴結採樣切除，以確定是否有轉移。

2. 部分肝切除術：可能需要切除部分被侵犯的肝臟。以及周圍組織。

3. Whipple 手術：靠近胰臟壺腹部位的膽管癌，就需要切除胰頭、膽囊、部分胃、部分小腸和膽管。

4. 肝臟移植：肝門或肝內膽管癌可能可以進行肝臟移植，但因為很快就會復發，目前仍不建議。

5. 緩和治療手術：如無法完全將腫瘤切除，為緩解膽管阻塞引起的症狀，減少膽道感染並提高生活品質，就會以下列方式進行：

  • 繞道手術：如果腫瘤阻塞膽管影響膽汁引流，則需在阻塞前的區域切開膽囊或膽管，將其繞過阻塞處或至小腸再縫合。
  • 支架置入：如果腫瘤阻塞了膽管，則可以進行手術或是以內視鏡方式置放支架，或繞過阻塞區域將膽汁排入小腸。
  • 經皮穿肝膽道引流：在肝臟中放入支架以將膽汁引流入小腸或體外的引流袋中。

二、放射線治療

放射治療是使用高能量放射線來殺死癌細胞。可能用在手術後，利用放射線照射腫瘤可能生長區域，殺除看不見、殘留的癌細胞，或是無法切除腫瘤時，達到局部控制，緩解症狀之目的。放射治療可能合併化學治療一起使用，以增加療效。放射線對正常細胞也會有影響，尤其是腸胃道黏膜表皮此類代謝率較快的細胞影響較大，因此在接受放射治療時，常會有噁心、腹瀉、腸胃不適等症狀，但療程結束就會改善。若合併使用化學治療時，副作用會變得更明顯。

為了增加放射治療對腫瘤的控制，減少圍繞腫瘤鄰近之正常組織所引起的傷害，目前的放射治療儀器多可精確定位，將劑量集中於照射區域，減少對周圍正常細胞的損傷。目前除了傳統的光子放射治療，近年來強度調控質子治療（intensity-modulated proton therapy，IMPT）與重粒子放射治療也成為膽管癌的治療方式，不僅降低副作用，也可達到疾病控制之療效。惟目前兩者皆須自費。

三、化學治療

利用抗癌藥物，透過口服或注射的方式至全身，毒殺生長分裂快速的癌細胞，以降低或清除體內的癌細胞，進而達到治療的效果。目前治療藥物有多種組合，也可能會與其他治療方式，例如放射治療，免疫治療等併用。化學治療一般作為外科手術治療的輔助療法，例如在一些接受手術的病人，給予術後輔助性化學治療可預防腫瘤復發，提高手術後之存活率。但若已有轉移，無法完全將腫瘤切除，或是已晚期，化學療法仍可能做為膽管癌的主要治療方式，藉著給予化學抗癌藥物來延長存活時間。經過臨床實驗顯示，複方化療（兩種）比單方的療效佳，也成為目前常用的治療準則。

四、標靶治療

隨著分子醫學的進展，癌症治療走向個別化精準醫療的時代。膽管癌在晚期階段治療選擇有限，且對標準化療反應率較差。近年來，透過次世代定序（NGS）等基因檢測技術，發現膽管癌中存在多種分子變異，如 FGFR2 融合、IDH1 突變、HER2 過度表現、BRAF V600E 等，促使多種標靶藥物逐步應用於臨床，提供了新的治療選項，改善病人的疾病控制與生活品質。

五、免疫治療

免疫治療主要是透過啟動免疫系統反應，進而辨識及攻擊癌細胞。目前使用的方式是將病人的腫瘤組織切片後進行特殊染色，藉由腫瘤細胞上的特殊標記來辨識療效。根據研究，免疫療法合併化療的使用可以降低死亡風險，提高存活率，有大約3成病友腫瘤明顯縮小，有2成5以上病友存活期大於2年。這樣的成果著實令人振奮。免疫治療與過去傳統治療相比具有多種優勢，但仍須經審慎評估身體功能，以確認其合適性。

六、其他治療

1. 射頻燒灼術（radio-frequency ablation, RFA）：在超音波或電腦斷層指引下，將電極探針穿過皮膚，插入腫瘤組織中，然後接上電源，射頻會轉換成熱能的形式，傳導於腫瘤細胞，造成凝固性壞死。在某些特定情況下可作為局部治療或緩和性處置，特別是在無法手術切除的病人或合併膽道阻塞的情況下。
2. 經導管肝動脈化學栓塞治療（Trans-arterial chemoembolization, TACE）：栓塞方式就是在血管攝影設備導引下，從鼠蹊部的股動脈，插入一導管到達血管，注入化學抗癌藥物（如Adriamycin、Cisplatin）後，再打入栓塞物質，將血管堵塞，阻斷血流供應，使癌細胞無法得到養分而壞死。當腫瘤仍侷限於肝內，無遠端轉移，且有明確的動脈供血來源，TACE 可作為區域控制方式。
3. 放射栓塞治療（Radioembolization）：於顯影下，自病人的鼠蹊部放置導管入肝臟，經由導管將幾百萬個含有放射性元素釔90（Yttrium-90）的微球體透過血液直接傳入腫瘤處，以近距離高輻射量殺死癌細胞，對於周圍器官也不會有傷害。針對無法手術切除或對化療反應不佳的局限性腫瘤。可作為局部控制之方式。
4. 光動力療法（Photodynamic Therapy, PDT）：是透過將光敏劑注射至體內，該藥劑會選擇性累積於腫瘤組織。當以特定波長的光線照射腫瘤區域時，光敏劑會產生光化學反應，釋放自由基與單態氧，進而誘發腫瘤細胞壞死。此療法具選擇性破壞癌細胞的能力，有助於延緩腫瘤進展、緩解症狀並提升病人生活品質。然而，無法有根治的效果，且因其光照深度有限，較適用於表淺性或管腔腫瘤病灶，臨床應用上仍存在一定限制。

結語

膽管癌治療以外科手術為優先選擇，將腫瘤及附近的病灶儘可能切除乾淨。但外科手術常面臨兩難，主要是長在肝門或總膽管附近的膽管癌，雖常以黃疸為臨床症狀，容易及早診斷出來，但因附近的血管及神經相當多，手術難度很高；相反的，長在肝臟裡面的膽管癌，雖較容易手術切除，卻因症狀不明顯，往往到了晚期才被診斷出來，導致預後不佳。至於其他方式的治療，例如化學治療、放射線治療及經動脈血管栓塞治療等的效果也有限。建議患有慢性膽道疾病者，應定期檢查追蹤，達到早期發現，早期治療，才能得到更好的控制。
