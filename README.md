# 台灣癌症基金會 網站改版提案

這是 [台灣癌症基金會](https://www.canceraway.org.tw/) 網站的**改版設計提案**，不是官方網站。內容取自原網站，版權屬於財團法人台灣癌症基金會。

## 裡面有什麼

| 路徑 | 內容 |
|---|---|
| `SITEMAP.md` | 用無頭瀏覽器逐頁爬過原網站後整理的網站地圖（原站沒有 sitemap.xml） |
| `docs/` | 產生好的新版網站（純 HTML/CSS/JS，可直接用 GitHub Pages 發佈） |
| `src/build.js` | 網站產生器：讀 `src/data/` 的內容，套版型輸出到 `docs/` |
| `src/assets/` | 設計系統（`style.css`）與互動（`main.js`） |
| `src/data/content.json` | 擷取並清理過的內容：30 種癌症、預防、服務、捐款、最新消息 |
| `src/data/crawl-index.json` | 爬取到的所有頁面清單（標題、日期、網址） |
| `src/make-sitemap.js` | 把爬取結果整理成 `SITEMAP.md` |

## 改版重點

1. **依身份分流**：首頁直接問「你今天想做什麼？」——預防癌症／治療與照顧／一起支持，三條路線。
2. **癌友諮詢專線常駐**：每一頁頂端與側欄都有 02-8787-3881，剛確診的人不用找。
3. **癌症依身體部位整理**：30 種癌症分成 7 個部位，可以輸入關鍵字或點部位篩選；內頁有段落快速跳轉。
4. **蔬果彩虹 579 五色當分類色**：五個顏色分別代表五大防癌習慣，頁首的五色線條也是同一套。
5. **捐款方式重整**：原本一長串的捐款方式，整理成可跳轉的分類與表格。
6. **手機優先、字放大、支援深色模式**，並有「跳到主要內容」等無障礙設計。
7. **新舊對照**：`docs/sitemap.html` 列出原網站每個選單項目在新版的位置。

## 本機預覽

```bash
node src/build.js          # 重新產生 docs/
npx serve docs             # 或任何靜態伺服器，打開 http://localhost:3000
```

## 發佈到 GitHub Pages

Repo → Settings → Pages → Source 選 `Deploy from a branch`，Branch 選 `main`、資料夾選 `/docs`。
（免費帳號的私人 repo 不能開 Pages，需要先把 repo 改成公開。）
